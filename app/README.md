# Fintness Feedback — Frontend

See the [project README](../README.md) for setup, and [backend/DEPLOYMENT.md](../backend/DEPLOYMENT.md) to connect Google Sheets.

```bash
npm run mock:api      # local stand-in for the Apps Script backend (port 8787)
npm run dev           # app on http://localhost:5173
npm run build         # production build → dist/
npm run test:backend  # backend logic tests
```
